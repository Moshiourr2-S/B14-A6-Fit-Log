# B14-A6-Fit-Log

> **A modern workout discovery and daily workout planning application built with Next.js, React, TypeScript, and Tailwind CSS.**

FitLog helps users discover workouts, view detailed exercise information, build a daily workout plan, and save workouts for later.

---

## 🚀 Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure |
| **CSS3** | Styling and layouts |
| **Tailwind CSS** | Responsive UI design |
| **JavaScript** | Application logic |
| **TypeScript** | Type-safe development |
| **React.js** | Component-based UI |
| **Next.js** | Application framework and routing |
| **REST API** | Fetching workout data |
| **LocalStorage** | Saving plans and saved workouts |
| **Git & GitHub** | Version control |

---

# ✨ Key Features

## 1. 💪 Workout Library

Browse workouts from the FitLog workout library.

Each workout card provides useful information such as:

- Workout name
- Muscle groups
- Equipment
- Duration
- Calories
- Rating
- Workout image

Users can click a workout to view its complete details.

---

## 2. 📋 Workout Details

Every workout has its own dynamic details page.

Users can view:

- Workout image
- Description
- Muscle groups
- Equipment
- Difficulty
- Sets
- Reps
- Duration
- Calories burned
- Rating
- Step-by-step instructions

Users can also add a workout to today's plan or save it for later.

---

## 3. 🗓️ Today's Workout Plan

Users can create their own daily workout plan.

The **My Plan** page displays:

- Total exercises
- Total workout minutes
- Total calories
- Selected workouts
- Workout difficulty
- Workout duration
- Workout calories

Users can:

- View workout details
- Mark workouts as completed
- Remove workouts from the plan

---

## 4. ❤️ Save Workouts for Later

Users can save workouts they want to use later.

The **Saved** section allows users to:

- Save workouts
- View saved workouts
- Open workout details
- Remove saved workouts
- Sort saved workouts

Saved workouts are stored locally in the browser.

---

## 5. ⚡ Responsive & Interactive UI

FitLog is designed to work across different screen sizes.

The project includes:

- Responsive navigation
- Responsive workout cards
- Mobile-friendly layouts
- Hover effects
- Interactive buttons
- Toast notifications
- Custom 404 page
- Dark fitness-themed interface
- Neon-lime accent design
